## العقد التعليمي العابر للموديولات

`Path → Optional Level/Stage → Subject → Main Skill → Optional Subskill`. السؤال الموثق ونسخته يقدمان دليلًا مرتبطًا بمهارة داخل نطاق `student+path+subject+skill`. تتكامل الأدلة مع التقييم والتصحيح السلطوي الموجود، ولا يُعاد حساب نتائج المحاولات التاريخية بصمت. **الذي لم يُقَس ليس ضعيفًا**، والتغطية تعتمد جميع مهارات الهدف المنشور، والجاهزية تتطلب شروط الهدف ونوع الدليل وثقته وأداء الزمن عند لزومه. لا خلط تلقائيًا لإتقان مسارات مختلفة، ولا احتساب المشاهدة أو التدريب بمساعدة كقياس مستقل.

## المستهلكون: مصدر حقيقة واحد وعروض مناسبة للأدوار

- **الطالب:** `/dashboard`، المسار الذكي، `/plan`، `/reports`، نتيجة الاختبار، التأسيس والمراجعة.
- **ولي الأمر:** `/parent-dashboard`، الابن المرتبط فقط.
- **المعلم:** `/school-teacher-dashboard`، ضمن المدرسة والفصل والمادة المكلف بها.
- **المشرف:** `/supervisor-dashboard` والتدخلات، ضمن التفويض.
- **مدير المدرسة:** `/school-director-dashboard` والتدخلات، ضمن مدرسته.
- **المحتوى/المدرب:** فجوات الأسئلة والتأسيس ضمن التكليف والصلاحية.
- **مالك المنصة:** `/admin-dashboard/reports` مركز «ذكاء التعلم والجاهزية» بجانب التحليلات الحالية؛ لا نضاعف مصدر التقرير.

## دورة التنفيذ القابلة للاستئناف

1. اقرأ الخطة والـCheckpoint؛ طابق GitHub `main` والفروع والـPRs والـCI والعمل المحلي الخاص بالوكيل. **لا تفترض أن ملفًا يعمل عليه Antigravity متاح للكتابة.**
2. راجع Codax للرحلة المستهدفة؛ اكتب Inventory `VERIFIED / PARTIAL / MISSING / UNKNOWN / BLOCKED` بأدلة.
3. اختر شريحة صغيرة مستقلة، واكتب اختبار فشل (RED)، ثم أصلح بأقل تغيير آمن في الموديول صاحب الحقيقة الحالي.
4. أثبت مسار `Legacy → React → HTTP → Go/Auth → PostgreSQL → persisted read → negative cases → RTL Playwright → exact-head CI` بحسب نطاق الشريحة.
5. سلّم PR مستقلًا (كاتب واحد لكل ملف)، وسجّل SHA/اختبارات/شواهد/متبقي/أول أمر استئناف في الـCheckpoint القائم. **لا توعد بتشغيل ذاتي أو دمج لم يحدث**.

## ما لا تعنيه هذه الوثائق

- ليست تعليمات لإيقاف Antigravity أو تغيير أولوية الهجرة.
- لا تفتح صلاحية للكتابة على Codax أو بيانات الإنتاج، ولا تمنح حق نشر أو تعديل درجات أو استحقاقات.
- أي نسب افتراضية أو وعود مطابقة خارجية أو وقت Solver ثابتة في مرفق تُعامل كفرضية تجريبية حتى المعايرة/القياس والتحقق.
- لا تُضاف خدمات منفصلة أو جداول أو محركات OR-Tools لمجرد ظهورها في المخطط؛ افحص الموجود ثم أثبت الحاجة.

**عند بدء جلسة جديدة:** اقرأ هذا الفهرس والوثيقة المرتبطة بشريحتك، ثم ارجع إلى **آخر حالة حقيقية للمستودع**. المرجع الدائم موجود هنا، أما حالة التنفيذ فتعيش في خطة الهجرة والـCheckpoint والـPRs.
