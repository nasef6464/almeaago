# ALMEAA V2 — خطة البناء التنفيذية

## الهدف
إعادة بناء ALMEAA داخليًا من الصفر مع الحفاظ على السلوك والواجهة الحالية، وإصلاح الأساس الهندسي بدل نقل الديون التقنية.

## المراحل
0. Foundation.
1. Identity/Auth.
2. Organizations/Schools.
3. Taxonomy.
4. Content/Foundation.
5. Question Bank/Media.
6. Assessment.
7. Learning/Adaptive/Review.
8. Commerce/Entitlements.
9. Communication/Parents.
10. Smart Classroom/Realtime.
11. AI.
12. Reporting/Operations.

## Gate لكل Domain
Schema -> Service -> Repository -> API -> React -> Authorization -> Unit -> Integration -> E2E -> Visual Parity -> PARITY_PROVEN.

## إدارة العمل
لا يبدأ تنفيذ واسع في Phase لاحقة قبل إغلاق Gate السابقة أو توثيق dependency صريحة.
