## 4. أدلة الفحص الجنائي لسلامة البيانات في قاعدة بيانات Neon

تم تنفيذ استعلام التدقيق المباشر على خادم Neon السحابي:

```sql
SELECT 
    (SELECT count(*) FROM questions) as total_questions,
    (SELECT count(*) FROM questions q LEFT JOIN question_versions qv ON q.id = qv.question_id WHERE qv.question_id IS NULL) as questions_without_versions,
    (SELECT count(*) FROM questions q LEFT JOIN question_skill_links qsl ON q.id = qsl.question_id WHERE qsl.question_id IS NULL) as questions_without_skills,
    (SELECT count(*) FROM question_versions qv LEFT JOIN assets a ON qv.image_asset_id = a.id WHERE qv.image_asset_id IS NOT NULL AND a.id IS NULL) as broken_asset_fks,
    (SELECT count(*) FROM (
        SELECT question_id, version, count(*) as opt_cnt 
        FROM question_options 
        GROUP BY question_id, version 
        HAVING count(*) != 4
    ) sub) as versions_without_4_options;
```

**النتيجة الرسمية المسجلة:**
