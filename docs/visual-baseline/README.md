# Visual Baseline Registry

The legacy ALMEAA UI is the reference.

For each critical screen, record:
- legacy route;
- user role;
- desktop screenshot reference;
- mobile screenshot reference;
- tablet/projector reference when relevant;
- key actions;
- loading state;
- empty state;
- error state;
- responsive notes;
- new route;
- parity status.

## Initial screen groups
1. Public/Landing/Auth.
2. Student Dashboard.
3. Path/Subject Learning Space.
4. Foundation topic/subtopic.
5. Course/Lesson.
6. Question Bank admin/editor/import.
7. Assessment center/builder.
8. Student assessment runner.
9. Results/question review.
10. Review/Mistakes.
11. Reports/Plans.
12. School Admin.
13. School Teacher.
14. Supervisor.
15. School Director.
16. Parent.
17. Smart Classroom teacher/student/projector.
18. AI admin.
19. Finance/Notifications/Operations.

Do not commit huge screenshot collections blindly. Keep image artifacts only when they materially help parity; metadata and screen contracts remain in Git.
