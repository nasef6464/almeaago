## 1. محتويات المجلد

- `capability-ledger.csv`: السجل الشامل لجميع قدرات المنصة عبر الـ 11 مجالاً، مع تتبع الأصل، والهدف، وحالة التنفيذ، والتحقق البصري والوظيفي والصلاحيات، والأدلة.
- `role-permission-matrix.csv`: مصفوفة الصلاحيات (الدور × الفعل × المورد × النطاق × شرط الاستحقاق × القرار المتوقع والدليل).
- `agent-ownership.csv`: جدول ملكية المهام والملفات المحددة لكل وكيل/منفذ لمنع تعارض الكتابة.
- `batches/`: عقود الدفعات وسجلات التحقق المستقلة:
  - `G0_BASELINE_AUDIT/`: استلام الجاري، تدقيق المستودعين، وتثبيت الـ Baseline.
  - `G1_STUDENT_DASHBOARD_DIMENSIONS/`: مطابقة أبعاد لوحة الطالب ومحاذاة الشاشات وإلغاء الفراغات.
  - `G2_MY_TRACKS_LIFECYCLE/`: دورة حياة مساراتي (اكتشاف، تسجيل، فتح، حفظ).
  - `G3_LEARNING_SPACE_FOUNDATION/`: مساحة التعلم، موضوعات التأسيس، مشغل الدروس الموحد.
  - `G4_ASSESSMENT_RUNNER_AND_REVIEW/`: مشغل الاختبارات التفاعلي، التدفق العلاجي، وتحليل المهارات الضعيفة.
  - `G5_STUDENT_SERVICES_AND_AI/`: أدوات المساعدة، المساعد الذكي، والتواصل (WhatsApp).
  - `G6_SCHOOLS_AND_PLATFORM_ROLES/`: منظومة المدارس ولوحات الأدوار الإدارية والتنظيمية.

## 2. قواعد التحديث والاستئناف
1. لا يُكتب في أي ملف إلا بواسطة المنفذ المسؤول عنه وفق `agent-ownership.csv`.
2. لا تُسجل أي قدرة كـ `VERIFIED` إلا بدليل تشغيلي مسجل (Exit Code 0، لقطة شاشة متطابقة، اختبار تكامل ناجح).
3. ملف التسليم الرسمي الموحد لجميع المراجعات هو `docs/migration/GEMINI_CURRENT_HANDOFF_AR.md`.
