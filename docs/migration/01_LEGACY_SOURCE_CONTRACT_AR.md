## 1. الغرض وحدود الادعاء

هذه وثيقة **مرجع اكتشاف وتعاقد** وليست شهادة أن كل موديول فُحص أو أن جميع الرحلات اختُبرت منشورة. الهدف استخراج ما يراه المستخدم وما يفعله النظام، مع أدلة ملفات واختبارات ولقطات شاشة قابلة لإعادة الإنتاج. اقرأ معها `../blueprint/00_MASTER_INDEX_AR.md`، لكن أعد التحقق من أي حكم قديم مقابل HEAD أعلاه قبل اعتماده.

## 3. المدرسة — العقد الأول ذي الأولوية

### لوحة مدير المدرسة — خريطة التنقل المثبتة في المصدر

`dashboards/school-director/directorNavigation.ts` يعرّف:

| القسم | ID | شرط الرؤية |
|---|---|---|
| الملخص العام | `overview` | `SCHOOL_OVERVIEW_VIEW` |
| الطلاب | `students` | `SCHOOL_STUDENTS_VIEW` |
| الفصول | `classes` | `SCHOOL_CLASSES_MANAGE` + `SCHOOL_CORE` |
| المعلمون والتكليفات | `teachers` | `SCHOOL_TEACHERS_ASSIGN` + `SCHOOL_CORE` |
| التعلم والجاهزية | `learning-evidence` | `SCHOOL_REPORTS_DETAILED_VIEW` + `SCHOOL_INTELLIGENCE` |
| اختبارات المدرسة | `assessments` | `SCHOOL_ASSESSMENTS_MANAGE` + `SCHOOL_ASSESSMENTS` |
| الحصص الذكية | `sessions` | `SCHOOL_SMART_CLASSROOM_VIEW` + `SMART_CLASSROOM` |
| الدعم والمهارات | `interventions` | إحدى صلاحيات التدخل + `INTERVENTION_CENTER` |
| التقارير والتصدير | `reports` | التقرير التفصيلي مع intelligence، أو تصدير مع executive analytics |
| النقل بين المدارس | `transfer` | `SCHOOL_STUDENTS_TRANSFER_SCHOOL` + `SCHOOL_CORE` |

**تنبيه:** إظهار الزر لا يثبت السلطة؛ تتبع خادم كل عملية ومدى المدرسة والعضوية وتاريخ الصلاحية.

### قاعدة مادة المعلم — فرق حديث واجب الفحص

في `server/src/modules/schools/application/teacherMaterialPolicy.ts` و`teacherMaterialScope.ts`، وفي `dashboards/school-director/DirectorTeacherAssignments.tsx`:

- مادة صريحة واحدة للتكليفات النشطة للمعلم داخل المدرسة؛ التكليف بلا مادة أو المتعارض لا يوسع الوصول.
- يجب فحص الإنشاء والتعديل، الاستعلام، بنك أسئلة الحصة، الانضمام، التقرير، وسحب التكليف معًا.
- يعرض المدير حالات التكليفات ويوقف التعارض؛ لا يكفي تعديل عنصر الإدخال في React.
- المصدر يوثق مقارنة اختيارية للحصص من المادة نفسها، مع عدم اختلاق اتجاه تطور عند خلط المواد.

### رحلة مدرسية عابرة للموديولات يجب تسجيلها

1. مدير المنصة ينشئ المدرسة وعقدها، ويمنح مديرًا صلاحيات محددة.
2. المدير ينشئ فصلًا ويربط/ينقل طالبًا دون هوية مكررة.
3. المدير يكلف معلمًا بمادة وفصل؛ يتغير نطاقه فور الإيقاف.
4. المعلم ينشئ اختبارًا/حصة ضمن التكليف ويرى أسئلة المادة المصرّح بها فقط.
5. الطالب يجيب؛ تبقى مفاتيح الإجابة خفية حتى وقت الكشف/التسليم الصحيح.
6. المعلم والمشرف والمدير يرون تقارير ضمن نطاقهم، مع تمييز المصدر (منصة/مدرسة/حصة).
7. تغيير المدرسة أو المادة أو الفصل يمسح الطلبات والحالة القديمة ولا يكشف بيانات السياق السابق.

## 4. قالب فحص كل شاشة (إلزامي)

لكل `screen_id` سجّل: URL، الدور، المدرسة/المادة/الفصل، ملف React، الاستدعاءات (`method`, `path`, request/response)، سياسة الخادم، الجداول/الـModels المتأثرة، الأحداث الجانبية، جميع الأزرار والنوافذ، حالات `loading/empty/error/disabled/success`, الرسائل العربية، RTL، لوحة المفاتيح، اللمس، الطباعة/التصدير، الفيديو/الصور والاختيارات. سجّل مصدر الحقيقة ورقم commit وتاريخ الصورة. أي حقل غير مفحوص يبقى `UNKNOWN`، لا `PASS`.

## 5. بروتوكول التصوير البصري والوظيفي

### مصفوفة Viewport أساسية (عرض × ارتفاع بالـCSS px)

| الجهاز | Viewport | الهدف |
|---|---|---|
| هاتف ضيق | `360×800` | التفاف النص والتنقل |
| هاتف شائع | `390×844` | الحوارات والبطاقات واللمس |
| هاتف عريض | `430×932` | عرض الاختيارات والجدول |
| تابلت رأسي | `768×1024` | breakpoint التنقل |
| تابلت أفقي | `1024×768` | أشرطة الأدوات والسبورة |
| لابتوب | `1366×768` | ارتفاع الصفحة وقوائم الإدارة |
| ديسكتوب | `1440×900` | عرض المحتوى والأعمدة |
| شاشة واسعة | `1920×1080` | المسافات والشاشة الكاملة/العرض |

مقاس الصورة الفعلي يتأثر أيضًا بـdevice pixel ratio؛ **ثبّت DPR والمتصفح والخطوط والتكبير** بين الطرفين. اختبر 320px إن ظهر حدّ انكسار. للسبورة وجهاز العرض أضف 1280×720 و1920×1080 في وضع projector. لا تكتفِ بثلاث صور الصفحة العامة القديمة.

لكل شاشة حرجة التقط **نسختين** من كل حالة: الأصل وGo بنفس الهوية والبيانات وبلا محتوى زمني متغير. الحالات: أول تحميل، بيانات فعلية، فارغ، خطأ، نافذة مفتوحة، قائمة مفتوحة، بحث/ترشيح، تبويب آخر، تمرير، استجابة لمس/لوحة مفاتيح. افحص التكوين، مواضع الأزرار، padding، الخط، الصور وقصّها، hover/focus، overflow، scroll، breakpoint والتفاعل؛ استخدم فرق الصورة آليًا وتقييمًا بشريًا للحالات الديناميكية. لا تستعمل بيانات إنتاج حساسة في الصور.

**الموجود سابقًا:** `../visual-baseline/exact-legacy-public-ui/` يحتوي صور 390/820/1440 ومستندات قياسات للصفحة العامة. هذه أدلة تاريخية وليست إثباتًا للشاشات الأخرى أو للتغييرات بعد لقطة المصدر.

## 6. نقاط منع الافتراض

- لا تنقل اختبارات تاريخية أو ممارسات قديمة إذا تغيرت العقود في `main`.
- لا تثبت نتيجة التصحيح من واجهة العميل؛ المصدر السلطوي في الخادم.
- لا تخلط عضوية المدرسة باستحقاق المحتوى، ولا دور المستخدم بتفويض المدرسة.
- لا تعتبر عدد الملفات أو وجود صفحة دليلًا على اكتمال الرحلة.
- لا ترحّل بيانات MongoDB الحية قبل جرد علاقاتها وخطة النسخ الاحتياطي والتحقق والرجوع.
