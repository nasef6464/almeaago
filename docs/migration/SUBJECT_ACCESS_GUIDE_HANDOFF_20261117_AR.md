# دليل الوصول للباقات في ساحة المادة

- يتيح كتالوج الباقات العام اختيار `pathId` و`subjectId` و`contentType` اختياريًا. عند الترشيح يطابق الخادم بنود الباقة وفق نطاق الاستحقاق الحالي؛ لا يجمع مادة من بند ونوع محتوى من بند آخر، ولا يعتبر باقة مسار أب صالحة للفرعي تلقائيًا. لا يوصي بباقة دورة محددة عند غياب معرف الدورة.
- تنتقل التدريبات والاختبارات والتأسيس والمكتبة المقفلة إلى نتائج المادة ونوع المحتوى، مع إمكانية عرض كل باقات المسار والعودة للمكان السابق. تعرض معاينة الباقة بيانات الكتالوج وتتبع الرابط، ويبدأ منها طلب الاشتراك.
- نجحت اختبارات Go وPostgreSQL محلي، ومنها رحلة HTTP متصلة تعرض الباقة للتدريب والتأسيس وتستبعدها من الاختبارات، واختبارات ترقيم الصفحات وعزل المادة والنوع. نجح فحص متصفح محاكى للتصفية وتغييرها ومعاينة الباقة وفتح واجهة الدفع، وروجعت لقطة المعاينة على الموبايل. عند النشر يلزم تحديث خادم Go قبل اعتماد الواجهة المفلترة.
- الدليل المكافئ للقديم **لم يكتمل**: التجميع يتطلب بيانات جميع الصفحات وتطبيق قواعد المحتوى والتجارة والاختبارات، والدورات الفردية وصلاحيات المدرسة، مع إبقاء المحاكي على مستوى المسار. لا يجوز استخدام أول 50 نتيجة أو تعميم صلاحية باقة على كل الدورات. ينبغي أن يعيد الخادم لكل فئة وجود المحتوى وحالاته الحقيقية، ويُظهر خطأ واضحًا عند تعذر التحقق.
- قبل اعتماد الدليل الكامل اختبر الزائر، طالبين بصلاحيات مختلفة، استحقاق المدرسة، دورة فردية، مزيج المجاني والمدفوع، أكثر من 50 عنصرًا، مادة مخفية، والمسار الفرعي والمحاكي. لا يثبت اختبار واجهة محاكاة أو قاعدة محلية واحدة تطابق المنصة بالكامل.
