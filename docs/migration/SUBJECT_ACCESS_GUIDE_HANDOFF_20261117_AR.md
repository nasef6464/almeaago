# دليل الوصول للباقات في ساحة المادة

- يتيح كتالوج الباقات العام اختيار `pathId` و`subjectId` و`contentType` اختياريًا. عند الترشيح يطابق الخادم بنود الباقة وفق نطاق الاستحقاق الحالي؛ لا يجمع مادة من بند ونوع محتوى من بند آخر، ولا يعتبر باقة مسار أب صالحة للفرعي تلقائيًا. لا يوصي بباقة دورة محددة عند غياب معرف الدورة.
- تنتقل التدريبات والاختبارات والتأسيس والمكتبة المقفلة إلى نتائج المادة ونوع المحتوى، مع إمكانية عرض كل باقات المسار والعودة للمكان السابق. تعرض معاينة الباقة بيانات الكتالوج وتتبع الرابط، ويبدأ منها طلب الاشتراك.
- نجحت اختبارات Go وPostgreSQL محلي، ومنها رحلة HTTP متصلة تعرض الباقة للتدريب والتأسيس وتستبعدها من الاختبارات، واختبارات ترقيم الصفحات وعزل المادة والنوع. نجح فحص متصفح محاكى للتصفية وتغييرها ومعاينة الباقة وفتح واجهة الدفع، وروجعت لقطة المعاينة على الموبايل. عند النشر يلزم تحديث خادم Go قبل اعتماد الواجهة المفلترة.
- أضيف دليل وصول المادة عبر `/api/v1/assessment-placements/subject-access-guide` للتأسيس والتدريب والاختبارات والمكتبة والدورات. يميز المجاني والمفتوح والمقفل والموجه، ويطبق صلاحية كل دورة على حدة؛ المحاكي يبقى على مستوى المسار. إذا تجاوزت الدورات 100 أو كانت تجارة دورة غير مهيأة يعلن أن حالة الدورات غير محسوبة بدل إظهار ملخص ناقص. وعند فشل الخدمة تعرض الواجهة إعادة المحاولة دون ادعاء الوصول.
- اختبارات التطبيق وHTTP وPostgreSQL المحلية غطت الزائر وطالبين والمحتوى الموجه ومزيج المجاني والمدفوع وأكثر من 50 موضوعًا والمخفي وقرار الدورة الفردية والباقة والمدرسة على مستوى مستودع الصلاحيات؛ ورحلة HTTP متصلة اختبرت فتح التأسيس بعد اعتماد الباقة لطالب واحد فقط. لم يُثبت استحقاق المدرسة برحلة متصفح متصلة كاملة، ولا يثبت ذلك تطابق المنصة بالكامل.
- أضيف تحميل صفحات موضوعات التأسيس بعد أول 50 بترتيب ثابت وحد 50، مع الحفاظ على أبناء الموضوعات والصلاحية وعزل الحساب وإعادة المحاولة. نجحت اختبارات المتصفح لتأخر الاستجابة وتبديل الطالب، واختبار HTTP متصل بـ PostgreSQL محلي. ما زالت قوائم الدورات والمكتبة تعيد أول 50 عنصرًا دون وسيلة لجلب الباقي. قبل النشر، يجب نشر خادم Go المتوافق مع الواجهة؛ لا تُعلن المطابقة الكاملة بناءً على هذه الاختبارات.
