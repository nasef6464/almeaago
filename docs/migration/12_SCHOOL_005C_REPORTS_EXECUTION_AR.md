# SCHOOL-005C-1 — ملخص نتائج الاختبارات المدرسية

**المصدر الملزم:** `almeaacodax` (Node/Mongo) — `DirectorAssessmentCards`، `schoolAssessmentReport`، `schoolAssessmentAudienceEvidence`، `schoolAssessmentLearners`.

**الهدف:** `almeaago` (Go/PostgreSQL/React). هذه الدفعة بعد دمج PR #133 الخاص بإنشاء الاختبارات.

## ما نُقل في هذه الدفعة

1. `GET /api/school-access/director/schools/{schoolId}/academic/assessments/{assessmentId}/report`؛ مصادقة وصلاحية `SCHOOL_ASSESSMENTS_MANAGE` **أو** `SCHOOL_REPORTS_AGGREGATE_VIEW` مع وحدة `SCHOOL_ASSESSMENTS` النشطة، والرد `private, no-store`.
2. استعلام PostgreSQL واحد يعيد التأكد من المدرسة والعضوية والصلاحية والعقد وقت القراءة. لا يجيب عن اختبار تملكه مدرسة أخرى.
3. الجمهور = مستخدمون نشطون لهم عضوية طالب نشطة بالمدرسة المحددة، وموجّهون صراحةً عبر كامل المدرسة أو الفصل النشط أو المستخدم؛ مع إزالة تكرار العضويات والتعيينات.
4. النتيجة = أحدث نتيجة مُرسلة مرتبطة بتكليف مدرسي داخل نفس المدرسة والاختبار، لا أحدث تدريب شخصي ولا نتائج مدرسة ثانية. الطالب يُحتسب مرة واحدة حتى مع تعدد المحاولات.
5. المؤشرات: المستهدفون، المكتملون، غير المكتملين، المتوسط، نسبة الاجتياز، أعلى وأقل درجة، مع `null` عند عدم وجود نتائج.
6. واجهة RTL متجاوبة من 390px حتى سطح المكتب في نافذة «النتائج والإدارة»، حالات تحميل/خطأ، إغلاق بالهروب ورفض إعادة استخدام بيانات مدرسة أخرى.

## حدود التغطية — لا نعرض بيانات مصطنعة

- `coverage.complete=false` دائمًا لهذه المرحلة؛ `started=null` مثل المصدر الذي لا يمتلك دليلًا مكتملًا للبدايات.
- تحليلات المواد والأقسام والمهارات مؤجلة لحين قراءة الأدلة المحفوظة وتحقيق عقد المصدر، وليست أصفارًا ذات دلالة.
- قائمة الطلاب التفصيلية وفلترة الغياب/الدعم ونتيجة الطالب تتطلب صلاحية `SCHOOL_REPORTS_DETAILED_VIEW` ووحدة `SCHOOL_INTELLIGENCE`؛ هذه دفعة 005C-2.
- الاستنساخ والتعديل والإخفاء والتذكير وإعادة الفتح: 005C-3.
- المطابقة البصرية الشاملة ومحتوى المعادلات/الصور على الأجهزة: 005D.

## الاعتماد

- اختبارات تطبيق Go + HTTP لاختلاف الدور والمدرسة، غياب الموديول، الرخصة والصلاحية: أُضيفت.
- اختبار تكاملي داخل `TestDirectorCreateAssessmentPostgres` مع قاعدة مهاجرة؛ يشمل فصلًا ومدرسة بالكامل ومحاولتين أحدثهما صحيحة ومحاولة دخيلة من مدرسة أخرى وطالبًا بلا عضوية نشطة وتعطيل العقد.
- Playwright (Mobile 390px) يتحقق من إظهار القيم المثبتة وإغلاق النتائج عند تغيير المدرسة.
- **الوضع:** الفحص المحلي ناجح، والفحص الحقيقي عبر GitHub Actions شرط مسبق للدمج؛ لا يُعد مكتملًا قبل البوابات الأربع.
