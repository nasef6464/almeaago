- نقاش الدرس: القديم يقرأ ويرسل للخادم؛ لا توجد خدمة مناقشات دروس مقابلة في كود الجديد المفحوص. أزلت الردود التجريبية وإيهام الطالب بإرسال رسالة للمدرب، واستبدلتها بملاحظات خاصة محلية مع توضيح عدم إرسالها، ومعزل لكل مستخدم ودورة ودرس. لم تُحذف بيانات localStorage القديمة ولم تُنقل تلقائيًا لعدم اقترانها بحساب محدد؛ توجد حاجة إلى معالجة آمنة إذا أريد استرجاعها. اختبار متصفح مع API محاكاة نجح للكتابة والتبديل وإعادة التحميل، وفحص الأنواع نجح. تنفيذ المناقشات الحقيقية وصلاحياتها وتوافق القديم ما زال مطلوبًا.
- عزل إجابات الفيديو التفاعلي محليًا حسب هوية الطالب والدورة والدرس، بدل المفتاح القديم المشترك بين حسابات الجهاز. لم تُحذف الإجابات القديمة غير المنسوبة ولا تُستخدم تلقائيًا. نجح اختبار متصفح مع API محاكاة لتجاهل إجابة طالب آخر واستعادة إجابة الطالب الحالي، ونجح فحص الأنواع. هذا تخزين محلي قابل للتعديل وليس إثباتًا خادميًا لإجابة الأسئلة الإلزامية؛ يلزم نقل التحقق إلى الخادم قبل الاعتماد عليه كشرط إكمال آمن. أصدر مشغل الوسائط تنبيه CustomEvent عند استعمال ملف فيديو اختباري فارغ؛ يحتاج تحقيقًا بمحتوى صالح.
- اختبارات الدورة: بطاقة الاختبار كانت تمرر معرّف البطاقة وتفتح قائمة عامة لا تستخدمه. في مشغل الدورة وصفحة تفاصيلها أصبح الزر يستخدم quizId الفعلي إلى مشغل الاختبار، مع رابط عودة للدورة، ويُعطّل البطاقة التي لا تملك رابطًا. أزيلت الاختبارات الافتراضية من صفحة التفاصيل، وصُحّح اسم المرحلة أثناء الدورة؛ لم يتغير حفظ البطاقات الإدارية القديمة. نجح فحص أنواع واختبار متصفح للوجهتين والبطاقة غير المرتبطة وطلب الرفض، باستخدام API محاكاة فقط. لم يثبت هذا أن بيانات presentation تنشئ مواضع اختبارات صالحة أو تكامل اشتراك الدورة؛ يلزم فحص إعداد المسؤول وقواعد الوصول على Go/PostgreSQL. ملفات افتراضية وزر تحميل تمثيلي ما زالا في CourseOverview ويحتاجان إصلاحًا مستقلًا.
- مرفقات الدورة: الإدارة كانت تنشئ اسم ملف بلا رابط أو بحجم افتراضي؛ أضيف إدخال رابط HTTP(S) والتحقق منه. أزيلت الملفات الافتراضية وزر التحميل الوهمي من صفحة الدورة، وأصبح الرابط الصالح يفتح والناقص يظهر غير متاح. استجابة ملخص الدورة العامة والتفاصيل دون صلاحية تحذف URL للملفات غير المجانية أو ذات سياسة غير معروفة، بينما تفاصيل المخوّل تحافظ عليه. نجح اختبار وحدة Go للملخص والتفاصيل ومرفق malformed، واختبارات حزمة HTTP للمحتوى، وفحص الأنواع، واختبار متصفح محاكى للمجاني والمغلق والرابط غير الصالح. لم يُختبر بعد حفظ الإدارة وشراء الدورة من طرف إلى طرف. الرابط الخارجي نفسه لا يصبح محميًا إذا كان منشورًا في مصدره؛ يلزم تخزين محمي أو روابط موقّتة لتحقيق حماية فعلية للملف.
