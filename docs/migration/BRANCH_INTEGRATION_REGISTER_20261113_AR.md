- نجح اختبار متصفح Chrome متصل بخادم Go وPostgreSQL محلية لتقدم درس دورة وإعادة التحميل وعزل طالبين. هذا الاختبار لا يغطي شراء الباقة عبر المتصفح؛ اختبار الشراء أعلاه عبر HTTP والخدمات. ظهرت تحذيرات الخطوط لأن خادم الاختبار المصغر لا يوفر خدمة إعداداتها. أغلقت قاعدة الاختبار بعده.
