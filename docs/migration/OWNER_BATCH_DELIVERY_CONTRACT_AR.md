# عقد تنفيذ دفعات ALMEAA مع المالك

اعتمد بتوجيه المالك في 2026-10-28. هذا عقد تنفيذ تابع للخطة النشطة `03_EXECUTION_AND_HANDOFF_PLAN_AR.md`، وليس خطة رئيسية جديدة. يسري على العمل المباشر وكل تشغيل للمهمة المجدولة يوميًا حتى التسليم المعتمد.

## النتيجة المطلوبة

نقل نفس واجهات ALMEAA الأصلية وتصميمها وسير استخدامها وروابطها وإعداداتها إلى Go/PostgreSQL، مع حفظ الوظائف السليمة الحالية وحدود الدومينات. لا إعادة تصميم صامتة، ولا إسقاط وظيفة أو إغلاق نطاق أكبر من الأدلة.

## التزام كل جولة

1. استرداد آخر HEAD وPR والتغييرات المحلية والأدلة، بصورة محدودة تمنع تكرار العمل. سجل الجدولة «قيد التنفيذ» وحده لا يثبت أن منفذًا يعمل أو أن الكود يتقدم.
2. تسمية الدفعة ومعيار قبولها قبل التنفيذ. الدفعة رحلة وظيفية مكتملة ذات نطاق واضح؛ مثل تعديل المدير ثم الحفظ والاسترجاع وظهور الأثر للمستهلك. لا يُجزّأ معيار القبول لاحقًا لمجرد إعلان إنجاز.
3. تنفيذ الرحلة واختبارها ومعالجة أسباب الفشل في الجولة نفسها ما دام ذلك ممكنًا. تحديث الحالة أو كتابة الخطة أو طلب تشغيل المهمة أو نجاح اختبار منفصل لا يعد دفعة وظيفية مكتملة.
4. استخدام المهارات والأدوات ذات الصلة، وإعادة استخدام الأصل والخدمات القائمة. كاتب واحد لكل فرع؛ تُفحص التغييرات الفعلية قبل تقرير وجود تداخل، ويستمر العمل المستقل المأمون عند تعذر الكتابة المشتركة.
5. إثبات الحفظ والعلاقات والصلاحيات عبر HTTP وGo وPostgreSQL معزول، والتنقل والرجوع والتحديث وحالات التحميل والفراغ والخطأ والمسودة بعد فشل الحفظ. اختبارات المحاكاة لا تستبدل دليل التخزين الفعلي.
6. للواجهات: صور أصل وجديد لنفس الدور والبيانات والحالة والمقاس عند 390 و820 و1440، وفحص بصري وتفاعلي. صورة جزء من المكون لا تثبت تطابق الشاشة أو الهيدر كاملًا. لا إخفاء للفروق أو تخفيف للاختبار حتى ينجح.
7. مراجعة وفحوص CI المطلوبة على SHA النهائي قبل الدمج المصرح. MERGED وTESTED لا تعنيان تكافؤ المنصة أو النشر للإنتاج.
8. تحديث سجل التسليم والخطة التابعة بالأدلة والخطوة التالية. لا تتوقف الجولة عند وعد بالعمل لاحقًا أو رسالة حالة فقط.

لا يمكن ضمان اكتمال أي نطاق خلال ساعة مهما كانت الأعطال؛ الساعة موعد بدء تشغيل، وليست مبررًا لإعلان نجاح غير مثبت. عند حد بيئي حقيقي: تُجرّب البدائل الآمنة، ويُحفظ العمل وcheckpoint دقيق، وتُعلن الدفعة غير مكتملة مع سببها ودليل المحاولات وما بقي. يستأنف التشغيل التالي نفس معيار القبول. لا اختلاق إنجاز ولا خفض للجودة لتحقيق رقم دفعات.

## تصحيح حالة الهيدر وأولوية المتابعة

إبلاغ المالك بأن النسخة التي شغّلها تختلف عن الأصل ملاحظة قبول مفتوحة؛ لا نعرف SHA نسخته، فلا ننسب إليها نتيجة من فرع آخر. استعادة بعض الهوية أو حفظ الإعدادات لا تساوي استعادة الهيدر كاملًا. الهيدر الكامل **PARTIAL / NOT PROVEN** حتى تجتاز قائمته وشكله وتفاعلاته وروابطه مقارنة فعلية مع الأصل.

فحص كود المصدر `components/Header.tsx` (blob `c4e45e5d9bd485538036e98f70eac42471a8fa71`، متحقق عبر GitHub) مقابل `LegacySiteHeader.tsx` في دفعة #155 أثبت:
