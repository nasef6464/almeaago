# ALMEAA SKILLS & PLUGINS SETUP PLAN
## خطة تجهيز وتشغيل مهارات وإضافات Google Antigravity لمنظومة المئة

> **تاريخ الإعداد:** 30 أكتوبر 2026  
> **حالة الخطة:** معتمدة للتهيئة والتفعيل الهندسي  
> **الهدف:** تمكين وكلاء Google Antigravity من العمل كفريق هندسي مؤتمت متكامل يمتلك الأدوات والمهارات المتخصصة لتنفيذ ومراقبة وإغلاق مشروع التحويل وفق أعلى المعايير الهندسية ودون أي تكرار أو كسر للتصميم الأصلي.

---

## 1. فلسفة البنية الموسعة لـ Antigravity في مشروع ALMEAA

يدعم Google Antigravity معمارية متقدمة للتخصيص والأتمتة تتكون من 4 طبقات رئيسية متكاملة:
1. **القواعد الملزمة (Rules - `AGENTS.md`):** تحدد المبادئ الحاكمة للمشروع (مثل: Legacy هو المرجع الحاكم بنسبة 100%، استقلالية مركز المهارات، منع إعادة التصميم الصامتة، وإلزامية الشرائح العمودية).
2. **المهارات المتخصصة (Skills - `SKILL.md`):** بروتوكولات وإرشادات قابلة للاستدعاء التلقائي أو اليدوي عند الحاجة لمهام محددة وتُخزن محلياً في `.agents/skills/` أو في مسار المهارات العام.
3. **خوادم البروتوكول المفتوح (MCP Servers):** أدوات برمجية وسيطة تتيح للوكلاء التعامل مع الأدوات الخارجية مثل متصفحات الفحص (Playwright / Chrome DevTools)، وقواعد بيانات PostgreSQL، وأنظمة Git.
4. **فرق الوكلاء (Teamwork & Subagents):** توزيع العمل التخصصي بين وكلاء محددين (Orchestrator, Explorer, Visual Verifier, Database/API Auditor, Quality Controller, Independent Auditor).

## 2. حزمة المهارات الـ 14 المخصصة لمنظومة ALMEAA

تم تصميم 14 مهارة متخصصة تغطي دورة حياة التحويل الهندسية بالكامل من فحص التطابق البصري حتى بوابات الإطلاق:

### 2.1 مهارة `almeaa-parity-checker` (فاحص التطابق البصري والهيكلي)
- **الهدف:** مقارنة عناصر الـ DOM والـ CSS والألوان والمسافات بين صفحات `almeaacodax` وصفحات `almeaago`.
- **أوقات الاستدعاء:** قبل إغلاق أي شريحة واجهة، أو عند استعادة مكون قديم.
- **المدخلات:** مسار الصفحة المستهدفة (مثال: `/category/:pathId`).
- **المخرجات:** تقرير مقارنة تفصيلي يحدد العناصر المفقودة (Missing Elements)، والفروقات في الألوان أو الـ Padding أو الخطوط، وحالة التطابق البصري.
- **مسار الملف:** `.agents/skills/almeaa-parity-checker/SKILL.md`.

### 2.2 مهارة `almeaa-db-migrator` (حارس ترحيل ومطابقة قواعد البيانات)
- **الهدف:** التحقق من مطابقة بنية البيانات بين MongoDB وPostgreSQL، وضمان صحة القيود والمفاتيح الأجنبية ومعاملات التزامن.
- **أوقات الاستدعاء:** عند كتابة أو تعديل أي ملف هجرة SQL (`migrations/*.sql`) أو استعلامات `sqlc`.
- **المدخلات:** اسم الكيان أو ملف الهجرة.
- **المخرجات:** التحقق من التكامل المرجعي، فهارس البحث، وجود قيود الـ ON DELETE المناسبة، ومنع قفل الجداول الطويل (Deadlock Prevention).
- **مسار الملف:** `.agents/skills/almeaa-db-migrator/SKILL.md`.

### 2.3 مهارة `almeaa-api-contract-validator` (مدقق عقود الـ APIs)
- **الهدف:** التأكد من أن مسارات Go Chi تعيد نفس هياكل الاستجابة (JSON Envelopes) ونفس أكواد الحالة (Status Codes) التي كانت تعيدها مسارات Express القديمة.
- **أوقات الاستدعاء:** عند ربط أي شاشة بمحرك الـ Backend أو إنشاء Endpoint جديد.
- **المدخلات:** مسار الـ API القديم ونظيره الجديد.
- **المخرجات:** تقرير مطابقة الـ Payload، مع التحقق من تطبيق الـ Strict JSON Decoder لمنع البيانات الزائدة.
- **مسار الملف:** `.agents/skills/almeaa-api-contract-validator/SKILL.md`.

### 2.4 مهارة `almeaa-rbac-audit` (مدقق الصلاحيات وعزل المستأجرين)
- **الهدف:** تدقيق حدود الصلاحيات للأدوار الستة (`student`, `teacher`, `admin`, `supervisor`, `school_admin`, `parent`) ومنع تسرب البيانات بين المدارس أو الفصول.
- **أوقات الاستدعاء:** قبل دمج أي ميزة تشمل المدارس أو لوحة الإدارة أو الحسابات.
- **المدخلات:** الدور ومسار المورد المطلوب اختباره.
- **المخرجات:** سيناريوهات اختبار عزل الصلاحيات، والتأكد من إرجاع HTTP 403 عند محاولة الوصول غير المصرح به.
- **مسار الملف:** `.agents/skills/almeaa-rbac-audit/SKILL.md`.

### 2.5 مهارة `almeaa-rtl-browser-verifier` (فاحص العرض العربي والاستجابة للشاشات)
- **الهدف:** تشغيل اختبارات Playwright للتحقق من الاتجاه العربي RTL، وسلامة الخطوط المعتمدة، وعدم تداخل النصوص على 3 مقاسات حتمية:
  - Mobile (390px - iPhone 14)
  - Tablet (820px - iPad Air)
  - Desktop (1440px)
- **أوقات الاستدعاء:** عند تعديل أي مكون واجهة أو إضافة نصوص عربية.
- **المخرجات:** لقطات شاشة موثقة في `docs/migration/evidence/` وسجلات الاختبار.
- **مسار الملف:** `.agents/skills/almeaa-rtl-browser-verifier/SKILL.md`.

### 2.6 مهارة `almeaa-pr-controller` (مراقب وموجه طلبات السحب PRs)
- **الهدف:** تنظيم دورة حياة فروع التطوير على GitHub وفق منهجية (RED Test ➔ GREEN Fix ➔ Clean Merge)، ومنع تداخل الفروع أو تكرار العمل.
- **أوقات الاستدعاء:** قبل فتح أي فرع جديد أو عند مراجعة الـ PRs المفتوحة.
- **المدخلات:** رقم الـ PR أو اسم الفرع المقترح.
- **المخرجات:** تصنيف الفرع، التحقق من عدم تعارضه مع `main`، وفحص سلامة الـ CI قبل الدمج.
- **مسار الملف:** `.agents/skills/almeaa-pr-controller/SKILL.md`.

### 2.7 مهارة `almeaa-learning-workflow-validator` (حارس رحلة تعلم الطالب)
- **الهدف:** اختبار الرحلة المتكاملة للطالب: فتح المسار ➔ بدء الدورة ➔ تشغيل الدرس وحفظ تقدم الفيديو ➔ بدء الاختبار ➔ تسليم الإجابات الذري ➔ استعراض بطاقة النتيجة ➔ مراجعة الأسئلة الخاطئة وتحديث المهارات.
- **أوقات الاستدعاء:** عند أي تعديل يمس مسارات التعلم والاختبارات ومحرك التصحيح.
- **المخرجات:** مسار تدقيق كامل للرحلة (Actor ➔ Screen ➔ HTTP ➔ Domain ➔ PostgreSQL).
- **مسار الملف:** `.agents/skills/almeaa-learning-workflow-validator/SKILL.md`.

### 2.8 مهارة `almeaa-school-director-validator` (حارس عمليات إدارة المدرسة والفصول)
- **الهدف:** تدقيق وظائف مدير المدرسة: مصفوفة الفصول الـ 12، البحث الحرفي في سجل الطلاب، تسلسل نقل الطلاب التزامني (Serial Moves لمنع الـ Race Conditions)، وإدارة حصص العرض الصفي.
- **مسار الملف:** `.agents/skills/almeaa-school-director-validator/SKILL.md`.

### 2.9 مهارة `almeaa-content-taxonomy-guard` (حارس تصنيف المحتوى وهرميته)
- **الهدف:** فرض هرمية التصنيف الصارمة (المسار ➔ المستوى ➔ المادة ➔ الموضوع ➔ المهارة ➔ السؤال ➔ الدرس)، والتأكد الحاسم من **بقاء مركز المهارات مستقلاً تماماً** داخل لوحة الإدارة ومنع محاولات دمجه داخل شاشات المسارات.
- **مسار الملف:** `.agents/skills/almeaa-content-taxonomy-guard/SKILL.md`.

### 2.10 مهارة `almeaa-arabic-normalizer` (معالج ومطابق النصوص والأرقام العربية)
- **الهدف:** توحيد مدخلات ومخرجات اللغة العربية، وتطبيع الأرقام الهندية المشرقية (٠-٩) إلى أرقام لاتينية (0-9) عند تسجيل الدخول أو إدخال الهوية الوطنية، ومعالجة تشفير المحارف المزدوج (Mojibake).
- **مسار الملف:** `.agents/skills/almeaa-arabic-normalizer/SKILL.md`.

### 2.11 مهارة `almeaa-commerce-tap-guard` (حارس التجارة وتكامل المدفوعات)
- **الهدف:** تدقيق تدفق الدفع عبر بوابة Tap، والتحقق من صحة توقيع الـ Webhooks، والتسجيل الذري في دفتر العمليات (Immutable Ledger)، وإصدار وتفعيل تراخيص المقاعد وأكواد الوصول.
- **مسار الملف:** `.agents/skills/almeaa-commerce-tap-guard/SKILL.md`.

### 2.12 مهارة `almeaa-ai-tutor-guard` (حارس ومراقب الذكاء الاصطناعي)
- **الهدف:** فحص واختبار المساعد الذكي، والتأكد من حدود الاستخدام اليومية (Rate Limits)، واستخدام الكاش الذكي للإجابات السابقة (`ai_question_assist_cache`) لمنع استهلاك الموارد المكرر.
- **مسار الملف:** `.agents/skills/almeaa-ai-tutor-guard/SKILL.md`.

### 2.13 مهارة `almeaa-ci-health-monitor` (مراقب خطوط الأنابيب والفحوصات الآلية)
- **الهدف:** مراقبة كافة مسارات GitHub Actions (`.github/workflows/*.yml`)، واكتشاف أسباب الفشل في بيئات الـ CI (مثل تعثر حاويات PostgreSQL أو أخطاء Playwright على الرانرز البعيدة)، وتصحيح تكوينات YAML فوراً.
- **مسار الملف:** `.agents/skills/almeaa-ci-health-monitor/SKILL.md`.

### 2.14 مهارة `almeaa-release-orchestrator` (منسق وحاكم تسليم الشرائح)
- **الهدف:** التحقق من اكتمال الشريحة العمودية بالكامل قبل الإعلان عن إنجازها، وجمع الأدلة الموثقة (تجميع Go، فحص TypeScript، نتائج الاختبارات، وتطابق الشاشات)، وتسجيل الإنجاز في وثائق الهجرة.
- **مسار الملف:** `.agents/skills/almeaa-release-orchestrator/SKILL.md`.

## 3. خطة تكامل إضافات المتجر وخوادم الـ MCP المدعومة

لتحقيق أقصى فاعلية هندسية، يتم تفعيل واستخدام الإضافات وخوادم الـ MCP التالية:

1. **إضافة Chrome DevTools / Playwright Browser Automation:**
   - تستخدم لتشغيل جلسات المتصفح الحية، والتقاط صور الصفحات للمقارنة البصرية المباشرة مع Legacy، واختبار تفاعل الأزرار والنوافذ المنبثقة.
2. **خادم PostgreSQL MCP Server:**
   - يتيح الاستعلام المباشر والفوري عن جداول قاعدة البيانات المحلية للتأكد من سلامة العلاقات، والتأكد من حفظ البيانات في الجداول الصحيحة فور تنفيذ الإجراء بالواجهة.
3. **أداة Git & GitHub Integration:**
   - التفاعل المباشر مع واجهة `gh` البرمجية لفحص الـ PRs، واستخراج سجلات الـ Actions، والتأكد من عدم فتح PRs مكررة على نفس الملفات.

`c:\almeaago\almeaago\.agents\skills\`

- أمثلة الاستخدام والقوالب التوضيحية لضمان التنفيذ الموحد والدقيق.
