## الشريحة المنفذة

- **الزائر ←** استعادة كلمة المرور / تعيين كلمة جديدة / تأكيد البريد.
- **UI ←** النماذج والأزرار والنصوص وترتيبها لم تتغير.
- **HTTP ←** الاستجابات غير الناجحة تُقرأ كنص مرة واحدة، ويُفك JSON إن أمكن، ويُحتفظ برسائل `error.message` و`message` و`error` النصية؛ وإلا يُستخدم نص HTTP حتى 240 حرفًا. الاستجابات الفارغة تحتفظ برسائل Go الاحتياطية السابقة.
- **Go/identity ←** لا تغيير في handlers أو المصادقة أو CSRF أو RBAC.
- **PostgreSQL ←** لا تغيير schema أو بيانات؛ فشل الطلب لا يُعد نجاحًا، والمحاولة التالية تعيد نفس المدخلات.
- **المستهلك ←** يظهر خطأ الخادم بدل النص العام مع بقاء البريد أو الرمز أو كلمة المرور قبل إعادة المحاولة.
