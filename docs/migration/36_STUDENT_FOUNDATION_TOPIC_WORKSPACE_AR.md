## الفجوة المثبتة من الكود
`LearningSpacePage` كان يعرض بطاقة تأسيس بلا حدث فتح أو استرجاع موضوع/فرعي، ولا نافذة الشروحات والدعم الأصلية؛ `tab` و`pathId` و`subjectId` محلية جزئيًا و`replace` يلغي تاريخ الرجوع، و`space` السابق قد يظل أثناء تغيير النطاق؛ فشل القراءة يعرض خطأ دون إعادة المحاولة. كان هناك شرح تقني داخلي ظاهر للطالب في تبويب التدريب والاختبارات.

## الشريحة المنفذة
1. نافذة التأسيس الأصلية بالحدود الممكنة: عنوان الموضوع، قائمة الرئيسية والفرعية، تبويبات الشروحات/التدريبات القصيرة/ملف الدعم، وحالة القفل. بطاقات الرئيسية تفتح النافذة؛ اختيار الفرعية والتبويب يحفظ في الرابط، ويمكن استرجاعه بعد reload/back/forward.
2. استهلاك `GET /api/v1/learning-spaces/foundation/{topicId}` الحالي، وهو عقد HTTP→Go Content Service→PostgreSQL `foundation_topics/topic_lessons/topic_library_items` مع فلترة المنشور والمعتمد والظاهر. لا إنشاء API جديد ولا نسخ بيانات.
3. الموضوع المقفول يعرض حاجز الباقة ولا يطلب تفاصيل مواضع الدروس. لا تشغيل تلقائي للفيديو، ولا إظهار محتوى درس غير مصرح به.
4. الرابط هو مصدر حقيقة النطاق والتبويب؛ تبديل المسار أو المادة يغلق موضوع النطاق القديم. رد `learningSpace` المخالف للنطاق يُرفض في Go application ويُرفض أيضًا في الواجهة. فشل التحميل يعرض إعادة المحاولة دون ضياع الاختيار.
5. إزالة نصوص وصفية تقنية تخص ترحيل Assessment من واجهة الطالب.
6. اختبار Playwright جديد: 390/820/1440؛ نافذة الشروحات والدعم، القفل، خطأ ثم retry، الفرعي/التبويب مع back/reload، تبديل المسار، وعدم التشغيل التلقائي. اختبار Go جديد لتطابق النطاق وانتشار خطأ repository.

## الحدود الصريحة
- **PARTIAL**: قائمة الشروحات والدعم حاليًا عناوين وملخصات فقط. لا تشغيل فيديو أو تنزيل ملف لأن GET learnerTopic لا يقدم جسم الدرس/رابط الملف المصرح، ويستلزم استكمال endpoint آمن بعقد منفصل قبل تفعيل الأزرار. لا نعرض أزرارًا وهمية.
- **PARTIAL**: التدريبات القصيرة المرتبطة بالموضوع ليست في learnerTopic؛ لا نفترض أن تدريبات المادة كلها تخص الموضوع.
- **PARTIAL**: المقارنة البصرية المقترنة Legacy↔Go بنفس الدور والبيانات ليست مثبتة؛ صور Playwright للهدف مع HTTP fixtures لا تساوي ذلك.
- **PARTIAL**: رحلة متصفح حقيقية مع Go/PostgreSQL معزول لم تُنفذ لهذه النافذة. Go repository الحالي يقرأ PostgreSQL؛ اختبارات الواجهة mock.
- لا تغييرات على schema أو RBAC أو scoring أو payments أو Legacy أو الإنتاج. لا دمج أو نشر.
