## الرحلة المنفذة

مدير → رابط `tab=homepage` الأصلي أو alias → مكوّن `HomepageManager` الأصلي → PATCH بجلسة وCSRF → خدمة content القائمة → PostgreSQL → GET عام → الشعار والهيرو ونصوص الأقسام وآراء الطلاب والمسارات المميزة للزائر.

أُعيد استخدام المكوّن الأصلي وtypes وsanitizer وavatar وحقول تجربة الطالب. استُبدلت اتصالات Legacy فقط بمحوّلات typed، دون نقل store أو صلاحيات أو درجات أو إنشاء دومين مكرر. قراءة كتالوج Go تسير عبر جميع الصفحات، وتحول `isVisible/workflowStatus` إلى حقول عرض الدروس الأصلية. التخزين والعلاقات واختبارات الصلاحيات الموجودة في #154 أُعيد استخدامها دون migration جديدة.

الحراسات الجديدة تمنع حفظ الإعدادات الافتراضية بعد فشل التحميل، وتوقف الحفظ حتى اكتمال الكتالوج، وتمنع تعديل المسودة أثناء PATCH، وتمنع قراءة قديمة من إلغاء حدث حفظ أحدث. تبقى المسودة عند فشل الحفظ. استُعيدت ألوان النص للأزرار الثانوية، ومعرض الصور الافتراضي، وحدود التدوير 3–60 ثانية، ومعالجة صور Legacy القديمة، وروابط CTA والبطاقة العائمة وتطبيع الشعار وفق المصدر.

## الأجزاء التابعة غير المكتملة

الضوابط التالية محفوظة في الشكل الأصلي، لكنها معطلة ومعلنة داخل الشاشة حتى نقل مستهلكاتها: تجربة الطالب، الشريط العلوي الكامل بما فيه pricing/blog/more، الإحصاءات الديناميكية، typography المحلية، اختيار الدورات والمقالات المميزة، وإدارة الإعلانات. لا يعرض النظام عدد إعلانات مصطنعًا. القيم المخزنة لا تُحذف عند عدم توفر الكتالوج.

مسارات المصدر `/courses` و`/pricing` و`/blog` ما زالت فجوات معروفة؛ لا تُستبدل برحلات أخرى بصمت. هذه الشريحة لا تمنح الوصول إلى محتوى بمجرد وجود featured ID. ظهور محتوى مخفي أو مدفوع يظل خاضعًا لخدمات الإتاحة، واختبار دورة نشر المحتوى كاملة لم يُنجز هنا.

## دليل الصور وحدوده

اختبار PostgreSQL المعزول يستخدم الجلسات الحقيقية وHTTP وGo والحفظ ثم reload وBack/Forward وقراءة الزائر. لا mock لاستجابات homepage أو auth أو CSRF. كتالوج الاختبار فارغ ومحدد صراحة لأنه خارج خادم presentation المعزول؛ ليس إثباتًا لكتالوج حي.

المقارنة الأولى للقسم داخل شاشة كاملة أعطت فرقًا بصريًا. القياسات أظهرت الأبعاد نفسها للهيرو (`366 × 5459.546875`) وموقعين مختلفين (`y=2422.5` و`2334.5`) بسبب حالة الضوابط المحيطة. تغيير الالتقاط إلى scroll0 لم ينهِ الفرق. لم يُخف الفرق ولم تُضف سماحية بكسلات.

الاختبار التالي يستخرج JSX لقسمي brand وhero من ملف المصدر المثبت وملف التنفيذ الفعلي إلى renderers اختبار مستقلة، مع الإبقاء على hooks والتحميل، ثم يعرضهما بالإطار وCSS والإحداثيات نفسها عند 390/820/1440. هذه مقارنة **قسم معزول بإطار مشترك**، وليست مقارنة تطبيق Legacy كامل أو شهادة لتخطيط الشاشة المحيطة. تُحفظ أيضًا صور المحرر الفعلي والصفحة العامة الفعلية. نجاح هذه المقارنة والبوابات الأربع على الرأس النهائي شرط الدمج، وتسجل النتيجة وروابطها النهائية في PR.
