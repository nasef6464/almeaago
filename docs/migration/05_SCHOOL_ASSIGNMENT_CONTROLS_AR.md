# SCHOOL-003 — تكليفات المعلم الحالية وإيقاف التكليف

**تاريخ التحليل:** 2026-10-27  
**المصدر المرجعي:** `almeaacodax/dashboards/school-director/DirectorTeacherAssignments.tsx` و`SchoolDirectorDelegatedOperations.tsx`  
**هدف Go:** `apps/web/src/features/organizations/pages/SchoolDirectorDashboardPage.tsx`  
**الحالة:** LOCAL IMPLEMENTATION & TARGETED E2E VERIFIED / REMOTE CI & REVIEW PENDING

## عقد السلوك المنقول من Node

1. تعرض شاشة مدير المدرسة قائمة التكليفات النشطة **للمعلم المختار** فقط، لا جميع معلمي المدرسة.
2. كل صف يظهر **اسم الفصل واسم المادة**؛ إن كانت المادة `NULL`/فارغة تاريخيًا يُعرض «مادة غير محددة»، وإن غاب اسمها من الكتالوج «مادة مسجلة».
3. يظهر التحذير عندما يوجد أي تكليف فعال بلا مادة أو أكثر من مادة مختلفة للمعلم المختار. الإيقاف متاح للسجل المخالف، ولا يُحذف السجل التاريخي.
4. يرسل «إيقاف التكليف» `teacherId` و`classId` و`subjectId` الأصليين مع `status: inactive` وCSRF إلى نطاق `/api/school-access/director/schools/{schoolId}/assignments`؛ لا يحتاج العميل `assignmentId` لاتخاذ قرار الاستهداف لأن عقد API يعتمد الثلاثية.
5. تعاد قراءة تكليفات المدرسة بعد نجاح العملية، وتظهر رسالة إتمام. أثناء الطلب تتعطل أزرار الإيقاف منعًا للتكرار.
6. لا تظهر شاشة التحكم دون `SCHOOL_TEACHERS_ASSIGN` و`SCHOOL_CORE`، وتستخدم مكونات متجاوبة على الهاتف والتابلت والكمبيوتر.

## تحقق طبقة Go الحالية

- `legacyAssignmentStatus("inactive")` يعيد `AssignmentStatusEnded`، ويعرض `presentLegacyAssignment` حالات `ended/revoked` على الواجهة باسم `inactive`.
- `UpsertAssignment` يتحقق من دور المدير أو صلاحية المدرسة المحددة؛ مستودع PostgreSQL يحدث سجل المطابقة `school_id + teacher_id + class_id + subject_id` في المعاملة ويحتفظ بتاريخ الإنشاء.
- يجب التعامل مع `subjectId: ''` التاريخي عند الإيقاف؛ رفض المادة الفارغة يخص إنشاء تكليف **نشط** فقط.

## معايير الاختبار والبوابات

- Playwright E2E: اختيار المعلم، ظهور الفصول والمواد، إخفاء حالات inactive، تحذير المادة التاريخية الفارغة، إرسال `inactive` مع CSRF ونطاق المدرسة، تحديث القائمة فور الاستجابة.
- صلاحيات: لا قائمة عند فقد الصلاحية/الوحدة.
- API: لا تعديل لمدرسة أخرى؛ اختبار 403/404 ونطاق العقد موجود جزئيًا في اختبارات التطبيق، ويحتاج تغطية مسار الإيقاف تحديدًا.
- تجربة سياق المدرسة: وصول رد قديم بعد تبديل المدرسة لا يعيد بيانات المدرسة السابقة. هذا خطر مستقل لم يغلق بعد.
- Gate: Backend, Frontend, Database, Frontend E2E على رأس الفرع نفسه، ولا دمج مع فحص أحمر.

## قرار التنفيذ

نستبقي `/api/school-access` لتوافق الواجهة مع نسخة Node، ونستخدم مكون قائمة صغيرًا مستقلًا مع callback للإيقاف في لوحة المدير. لا migration لقاعدة البيانات، ولا استبدال لواجهة المدير التي بُنيت سابقًا؛ الإضافة على العقد المرئي الحالي فقط.
