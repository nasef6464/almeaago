# SCHOOL-005C4 — إعدادات منشئ الاختبار المدرسي

مرجع المطابقة: `almeaacodax/dashboards/admin/QuizBuilder.tsx`، تبويب «الإعدادات»، و`almeaago/migrations/000020_assessment_foundation.up.sql`.

## ما أضيف

أصبح مدير المدرسة يحدد في نفس شاشة الإنشاء:

| إعداد المنشئ القديم | الحقل في طلب Go | التخزين المعتمد في PostgreSQL |
|---|---|---|
| درجة النجاح | `settings.passingScore` (0–100) | `assessment_versions.passing_score` |
| الوقت بالدقائق / الصفر دون حد | `settings.timeLimitMinutes` (0–1440) | `time_limit_seconds`، الصفر `NULL` |
| عدد المحاولات | `settings.maxAttempts` (1–100) | `max_attempts` |
| طريقة الاختيارات | `settings.optionLayout` | `option_layout` |
| خلط الأسئلة / الاختيارات | `randomizeQuestions` / `randomizeOptions` | `randomize_questions` / `randomize_options` |
| شريط التقدم / وجوب الإجابة | `showProgressBar` / `requireAnswerBeforeNext` | الأعمدة المناظرة |
| مراجعة الأسئلة / إظهار الإجابات | `allowQuestionReview` / `showAnswers` | الأعمدة المناظرة |
| تقرير النتيجة / الشرح | `showResultsReport` / `showExplanations` | الأعمدة المناظرة |

- الحقول كلها داخل `settings` اختياري. طلبات API القديمة التي لا ترسل الإعدادات تحتفظ بالقيم الافتراضية الحالية، كما تبقى بصمة Idempotency التاريخية متوافقة.
- `false` و`0` قيم مقصودة وغير قابلة للاستبدال بالقيم الافتراضية. تحفظ إعدادات الطلب مع النسخة المنشورة من الاختبار داخل **نفس معاملة النشر**.
- لا توجد جداول إضافية أو إلغاء لأي سلوك فعّال. الاختبار يظل موجهًا للمدرسة ولا ينشر للمنصة العامة.
- الواجهة تستعمل إدخالات مؤطرة ومقاسات مرنة من الجوال إلى الكمبيوتر؛ وتظل قاعدة عرض اختيارات الجوال عموديًا.

## دليل القبول

1. اختبارات `DirectorAssessmentSettingsValidation` ترفض درجات ومُدد ومحاولات ونمط عرض خارج النطاق.
2. اختبار بصمة النشر يثبت أن تغيير المدة بنفس مفتاح النشر لا ينشئ نسختين مختلفتين خلسة.
3. اختبار PostgreSQL يقرأ النسخة المنشورة ويتحقق من الوقت بالثواني والدرجة والمحاولات واختيارات `false`.
4. اختبار Playwright يضبط القيم من الواجهة ثم يؤكد جسم طلب API والمقاسين 390/1440.
5. أربع بوابات GitHub هي معيار الدمج: Backend / Database / Frontend / Frontend E2E.

## حدود واضحة

هذه الدفعة لا تدّعي نقل **كل** منشئ الاختبارات الموحد القديم: جدولة فتح وإغلاق الاختبار، تحرير نسخة بعد النشر، الأرشفة، وأبعاد تقارير التحليل التفصيلية لها مراحل مستقلة.
