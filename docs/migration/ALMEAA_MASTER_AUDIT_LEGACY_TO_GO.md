## 1. وثيقة الحوكمة ومنهجية التدقيق المستقل

### 1.1 الحدود والضوابط الصارمة المطبقة في هذه المرحلة
- **تدقيق قراءة واختبار فقط (Read-Only):** لم يتم تعديل أي سطر في كود الإنتاج، ولم يتم إنشاء أو دمج أي PRs جديدة، ولم يتم تعديل قواعد البيانات الحية.
- **منع التخمين والهلوسة بنسب الإنجاز:** لا تُقبل أي نسبة إنجاز تقديرية ما لم تكن مدعومة بمسار الملف الفعلي، واسم المكون، وأرقام الاختبارات، وحالة التكامل مع Go وقاعدة بيانات PostgreSQL.
- **المرجع الحاكم الوحيد:** مستودع `almeaacodax/main` هو المرجع الملزم للتصميم، وترتيب القوائم، وتدفق التعلم، ومسارات التنقل، وسلوك الأزرار، والخطوط، والمسافات، ودعم الاتجاه RTL. يمنع أي إعادة تصميم تلقائية.

### 1.2 حالة بيئة التشغيل المحلية الحية (Verified Runtime State)
تم التحقق الميداني المباشر من تشغيل الخدمات الخمس الأساسية على الجهاز المحلي بنجاح تام:
1. **قاعدة بيانات PostgreSQL 18.6:** تعمل بنجاح على المنفذ `5432` (قاعدة `almeaa` تحت المستخدم `almeaa`). تحتوي على **111 جدولاً** مكتملة عبر 45 ملف هجرة SQL (`migrations/000001` إلى `migrations/000045`).
2. **سيرفر التخزين المؤقت Redis 8.10:** يعمل بنجاح على المنفذ `6379` لدعم الجلسات، وعزل الـ Tokens، وإشارات الغرف الصفية والـ Sockets.
3. **سيرفر Go Backend API:** يعمل بنجاح على المنفذ `8080` (ملف `api.exe`). استجابة فحص الصحة `/health/live` تعيد `{"service":"almeaa-api","status":"ok"}`، واستجابة الجاهزية `/health/ready` تعيد `{"status":"ready"}` مع تأكيد الاتصال النشط بقاعدة بيانات PostgreSQL.
4. **سيرفر Go Worker الخلفي:** يعمل بنجاح (ملف `worker.exe`) لمعالجة حملات الإشعارات، ومعالجة أحداث التجارة، وتوليد مهام خطة التعلم.
5. **سيرفر الواجهة الأمامية React / Vite:** يعمل بنجاح على المنفذ `5173` (فحص HTTP يعيد `HTTP/1.1 200 OK`). تم التحقق من تجميع الكود وفحص الأنواع بـ TypeScript (`npm run typecheck`) بدون أي خطأ (`0 errors`).

## 3. تدقيق الـ APIs وعقود الخدمات (API Endpoints & Contracts Audit)

### 3.1 مقارنة الحجم المعماري وتوزيع المسارات
- **في Legacy (Node.js/Express):** 26 ملف مسارات تضم **226 مسار API نشط**. تعتمد بنية استجابة غير موحدة في بعض الوحدات (`{ success: true, data: ... }` مقابل استجابات مباشرة)، وتعتمد على MongoDB ObjectId strings.
- **في Target (Go Chi):** 36 ملف Handler تضم **284 مسار API نشط** تحت البادئة `/api/v1/` إضافة إلى بادئة التوافق العكسي `/api/school-access/`.
- **معمارية Go المعتمدة:** Clean Architecture / Domain-Driven Design بمستويات صارمة:
  `Transport (HTTP Chi)` ➔ `Application (Services & Use-Cases)` ➔ `Domain (Entities, Value Objects, Policies)` ➔ `Repository (PostgreSQL with sqlc & pgx)`.

### 3.2 سلامة العقود وصندوق الأخطاء (Error Envelopes & Strict JSON)
1. **عزل الأخطاء (Fail-Closed Semantics):**
   - تم التحقق من رفض أي مدخلات JSON تحتوي على مستندات متتالية أو غير منسقة عبر `strict JSON decoder` في حزم الهوية والمحتوى والتقييم (مثل PR #210 و PR #224).
   - يتم إرجاع رسائل الخطأ العربية الأصلية دائماً لمنع تسرب تفاصيل النظام الداخلي، مع الحفاظ على أكواد الـ HTTP القياسية (400 للتحقق، 401 للمصادقة، 403 للصلاحية، 404 لعدم الوجود، 409 للتزامن).
2. **توافق مسارات المدارس القديمة (Legacy School Access Compatibility):**

## 5. تدقيق الصلاحيات والـ RBAC والهوية (RBAC, Multi-Tenancy & Identity)

### 5.1 الأدوار الستة المعتمدة وتطابقها
تم التحقق في `internal/identity/domain/user.go` من اعتماد الأدوار الستة ذاتها دون اختراع أي دور جديد:
1. `student`: الطالب (وصول للمسارات، الاختبارات، الخطة، المراجعة، النتائج).
2. `teacher`: المعلم (وصول لمساحة عمل المعلم، الفصول المسندة، متابعة الواجبات، بنك الأسئلة للمادة).
3. `admin`: مدير المنصة (وصول كامل لكافة شاشات لوحة الإدارة، مركز المهارات، الهوية، التجارة، والمستخدمين).
4. `supervisor`: المشرف التربوي (متابعة مؤشرات أداء المدارس المسندة، التدخلات الأكاديمية، والتقارير الإحصائية).
5. `school_admin`: مدير المدرسة (إدارة المعلمين، الطلاب، الفصول، توزيع الاختبارات المدرسية، وشاشات العرض الصفي).
6. `parent`: ولي الأمر (ربط الأبناء، متابعة مستوى الإنجاز والدرجات عبر لوحة مخصصة).

### 5.2 قنوات تسجيل الدخول الذكي وتطبيع الأرقام (Smart Login)
- يدعم Go المحلل الذكي لتحديد نوع المدخل تلقائياً: البريد الإلكتروني، رقم الهاتف، أو الهوية الوطنية المكونة من 10 أرقام تبدأ بـ 1 أو 2.
- يتم تطبيع كافة الأرقام المكتوبة بالأرقام الهندية العربية (٠١٢٣٤٥٦٧٨٩) إلى أرقام قياسية (0123456789) قبل معالجة التوثيق لمنع فشل الدخول الصامت.
