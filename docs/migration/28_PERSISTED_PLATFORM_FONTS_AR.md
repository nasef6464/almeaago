## العقد والتنفيذ

مدير → إدارة خطوط المنصة → نفس `PlatformFontsManager` وحقول/بطاقات/معاينة/رفع/إعادة ضبط/حفظ الأصل → `api.ts` مع الجلسة وCSRF الحاليين → `PATCH /api/v1/content/platform-font-settings` → `content.FontService` → `ParseFontPatch` → PostgreSQL `content_platform_font_settings` → `audit_logs` في المعاملة نفسها.

الزائر → `PlatformFontBootstrap` → GET المسار نفسه → تطبيق الإعدادات على متغيرات CSS والأنماط مثل الأصل. لا Mongo ولا تغيير صلاحيات أو تصحيح أو مدفوعات أو بيانات إنتاج.

أعيد استخدام مصدر العرض مع baselines وSSR يقارن كامل markup في حالتي التحميل والمحتوى. التعديلات: imports، نداء CSRF، تحييد اسم الخط في CSS، ومنع رد bootstrap متأخر من استبدال المعاينة أو الحفظ. واجهة الإدارة المحيطة والتنقل الشامل لم يثبت تطابقهما؛ أضيفت خانة الخطوط بنفس اسم وأيقونة المصدر في shell القائم.

PATCH يحافظ على الحقول الاختيارية غير المذكورة، ويفرغ override عند النص الفارغ؛ أسر الخطوط الأربع تعود إلى `tajawal` عند غيابها كما في Zod الأصل. حدود الرفع 500000 بايت و700000 محرف لكل خط، وحجم الطلب 1500000 بايت لاستيعاب خطين. عدد المحارف يطابق وحدات UTF-16 في المصدر. بقية طلبات المحتوى لم يتغير حدها. GET لا يكتب عند غياب السجل. migration إضافية قابلة للعكس في بيئة اختبار فقط.

## الأدلة التنفيذ والتدرج

- اختبار العقد فشل أولًا لغياب التنفيذ ثم نجح؛ مقارنة التطبيع والخيارات وكامل SSR وحماية CSS: 3/3 PASS.
- اختبارات content Go وجميع حزم Go محليًا PASS؛ اختبار PostgreSQL مشروط ولا يدعي النجاح دون `DATABASE_URL`.
- المتصفح المحلي تعطل SIGTRAP قبل التنفيذ؛ هذا BLOCKED محلي وليس نجاحًا وظيفيًا.
- أضيف إلى Database CI اختبار Go HTTP بجلسات دخول حقيقية وPostgreSQL مع Playwright للحفظ والتحديث والمعاينة والرجوع والرفع على 390/820/1440، دون اعتراض استجابات الخطوط. الجداول المؤقتة تعزل الخطوط والتدقيق؛ الحسابان تجريبيان ويحذفان بعد الاختبار. النتيجة النهائية تسجل بعد التشغيل.
- اختبارات Font E2E المحاكية منفصلة لحالات رفض الحفظ والتحميل والدور والرد المتأخر؛ لا تسمى دليل DB.
- المراجعة المستقلة لم تجد عيبًا مهمًا أو حرجًا. فرق حدود UTF-16 ثبت باختبار فاشل ثم صُحح. أضيفت مسارات العرض إلى مرشحات CI لكي لا تتجاوز التعديلات اللاحقة الاختبارات.
- ملاحظة موروثة غير مانعة: اكتمال FileReader أثناء تعديل حقل آخر قد يعيد حالة قديمة في مكوّن المصدر. لم تغير هذه الدفعة سلوك الرفع الموروث؛ يسجل لفحص مستقل بدل إعادة تصميم صامتة.
