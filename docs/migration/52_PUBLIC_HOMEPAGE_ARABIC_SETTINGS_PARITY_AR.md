## التحقق والحدود
- أول اختبار متصفح أُضيف قبل الإصلاح، لكن تشغيل RED الأول أُلغي بسبب concurrency بعد تحديث الفرع؛ لا يُدّعى إثبات RED تشغيليًا.
- فشل Frontend CI وسيط بعد إدخال الاستيراد الجديد بسبب محمل الاختبار القديم `Cannot find module './homepageSanitizer'`، وأُصلح السبب دون حذف الاختبار.
- على `b69f197d20be41396fa6fa16cefbdb74f1b060e6`: Frontend CI وDatabase CI وFrontend E2E نجحت؛ 139 اختبار متصفح ناجحًا و3 متجاوزة، منها الاختبارات الثلاثة الجديدة. تحديث الصور اللاحق يحتاج إعادة تحقق على SHA النهائي.
- Backend CI لا يُفعّل عادة بتغيير هذه الملفات فقط، ولا يُعد PASS ضمن هذه الشريحة.
- صور Go وحدها لا تثبت مطابقة Legacy؛ لا توجد جلسة Legacy بنفس بيانات الاختبار هنا.
- اختبارات HTTP محاكية لا تثبت رحلة حفظ المدير إلى PostgreSQL في هذا الاختبار تحديدًا؛ Database CI يجري اختباراته المستقلة.
- لا تغيير للـRBAC أو scoring أو payments أو schema أو ملفات الفرق الأخرى أو الهيدر الجاري في #159.

## تحديث 29 أكتوبر 2026 — سلامة التحديث الجزئي للزائر

**الفرق المثبت:** كان مستهلك الرئيسية يستبدل مستند الإعدادات كله بحدث `homepage-settings-updated` حتى إذا احتوى الحدث على `brand` فقط. ويستدعي `sanitizeHomepageSettings` الذي يقرأ `hero.badgeText`، فينتج `TypeError` عند غياب `hero` ويضيع محتوى الرئيسية السابق. هذا عقد حماية للمستهلك عند حدث جزئي؛ حدث حفظ المدير العادي يرسل مستندًا كاملًا.

**RED تشغيلي مثبت:** أضيف اختبار `partial homepage save events preserve omitted fields...` قبل الإصلاح، وفشل في Frontend CI عند `dd1055cdc7568ee7da49f960e6955e1fda70b665`، تشغيل [40946753844](https://github.com/nasef6464/almeaago/actions/runs/40946753844)، مع `TypeError: Cannot read properties of undefined (reading 'badgeText')` وظهور قيمة الشعار القديمة.

**الإصلاح:** دمج حقول الحدث الجزئي في الحالة السابقة قبل التطبيع؛ دمج كائنات `hero/brand/sections/typography/navigation` مع الحفاظ على الحقول غير المذكورة، واستبدال المصفوفات المذكورة صراحة (بما فيها `[]`) بدل إضافتها. رفض الأحداث غير الكائنية أو `null` دون إبطال GET. استمر منع GET القديم من الكتابة فوق تحديث أحدث.

**الاختبارات المضافة:** اختبار وحدات يغطي تحديث الشعار دون مسح العنوان، وتحديث العنوان الجزئي، والإفراغ الصريح، واستمرار حقول التنقل والإحصاءات، وتجاهل حدث غير صالح. توسيع اختبارات المتصفح عند 390/820/1440 RTL لإرسال حدث شعار فقط ثم حدث عنوان جزئي، مع صور إضافية للحالة الجزئية.

**الحدود:** لا تغيير لواجهة المدير أو الهيدر أو API أو PostgreSQL أو الصلاحيات. نتائج CI النهائية تُقرأ من رأس PR #195؛ الصور من Go فقط وليست مقارنة مزدوجة مع Legacy. الرحلة الحقيقية من حفظ المدير عبر Go/PostgreSQL إلى متصفح الزائر ما زالت PARTIAL حتى تشغيلها على بيئة تكامل معزولة.
