## الفجوة المثبتة
تُعيد قاعدة مراجعة الطالب بطاقة محفوظة برقم سؤال وإصدار مثبت. إذا أعادت خدمة الأسئلة قائمة إسقاطات ناقصة، كان `ReviewLibrary` و`ReviewPractice` يتجاوزان البطاقة ويعيدان HTTP 200 مع قائمة فارغة أو ناقصة. هذا **ليس إثباتًا لعدم وجود بطاقة**، وقد يعرض للطالب حالة فراغ كاذبة.

## التعديل
- عند فقد الإسقاط المثبت `questionId + questionVersion`، ترجع خدمة التعلم `ErrIncompleteReviewProjection` ولا تصدر قائمة ناقصة ناجحة. يحوّل HTTP `writeError` الخطأ غير المعروف إلى 500 برسالة عامة، بدل 200 مضلل؛ تعرض الواجهة القائمة رسالة الخطأ الموجودة أصلًا.
- يظل الفراغ الحقيقي (لا بطاقات من المستودع) نجاحًا عاديًا.
- في التدريب، يبقى سلوك تخطي سؤال موجود لكن غير صالح للتدريب (دون مفتاح إجابة/اختيارات) كما كان؛ لم تتغير معادلات التصحيح أو بنية السؤال.
- لا تعديل على `PR #161` للصور، أو `PR #163` لمشغل الدروس، أو `PR #171` للوحة الطالب، أو `PR #186` للمستودع؛ لا تغيير DB/schema/RBAC/payments/scoring.

## رحلة العقد وحدودها
الطالب → «أسئلتي للمراجعة»/جلسة المراجعة → GET `/api/v1/review/library` أو `/api/v1/review/practice` → `internal/learning/transport/http` → `application` → مستودع بطاقات الطالب PostgreSQL → إسقاط سؤال مثبت من QuestionBank → واجهة الخطأ/البيانات.  
تغطي اختبارات Go الجديدة فقد سؤال واحد، فقد جزء من الدفعة، فقد سؤال التدريب، والفراغ الحقيقي. **لا تدّعي** هذه الاختبارات وجود جلسة متصفح/HTTP/PostgreSQL حقيقية مقترنة بالنسخة القديمة؛ يلزم تشغيل مع بيانات اختبار معزولة ولقطات RTL 390/820/1440 قبل اعتماد تكافؤ الشاشة.
