# مناقشات دروس الدورات — متابعة محلية

- القديم يوفر مناقشات للدرس والدورة وردودًا وحلًا للمناقشة. أضيفت هنا شريحة **مناقشات درس الدورة فقط**؛ لا تدّعِ استكمال مناقشات الدورة العامة أو المحاكي أو علامات الحل والإدارة.
- تحفظ `000062_lesson_discussions` الرسائل في PostgreSQL حسب الدورة والدرس والمؤلف. لا تطبّق الترحيل على الإنتاج قبل تجهيز النشر والتحقق والنسخ الاحتياطي. تراجع الترحيل يرفض حذف جدول به رسائل.
- نقاط `GET/POST /api/v1/learning-spaces/courses/{courseId}/lessons/{lessonId}/discussion` تتطلب تسجيل الدخول؛ الكتابة تتطلب CSRF ومفتاح `requestId` ثابتًا عند إعادة المحاولة. تتأكد الخدمة من ارتباط الدرس بالدورة وصلاحية الطالب الفعلية أو صلاحية المدرب المالك/المسند أو الإدارة. الرسائل يراها الأشخاص المصرح لهم بالدرس، وليست رسائل خاصة.
- تبقى الملاحظات الخاصة على الجهاز منفصلة عن المناقشات. تظهر واجهة إرسال وردود محمية من تبديل الدرس وتأخر التحميل وتكرار الإرسال. يشير الرد إلى السؤال الأصلي إن كان محملًا أو يوضح أنه غير معروض.
- أضيف تبويب مناقشات الدروس في محرر الدورة الحقيقي؛ يختار المدرب الدرس المنشور ويرد دون شراء الدورة، مع التحقق من تكليفه ونطاق تأليفه. أضيف رابط من لوحة المدرب لإدارة المحتوى الفعلي، وتنبيه لأن بقية بيانات اللوحة الحالية تجريبية. لا يوجد صندوق جامع لكل المناقشات أو إشعارات، ولا أدوات حل أو حذف أو ترحيل للمناقشات القديمة.
- اختبر الوكيل خدمة التطبيق وHTTP والتحقق من CSRF والصلاحيات، وPostgreSQL محليًا لتكرار المفتاح وعزل الدرس. نجح اختبار HTTP متصل بباقة دورة مع منع القراءة قبل الشراء ولحساب آخر ثم السماح بعد موافقة تحويل تجريبية. نجح متصفح متصل بخادم Go وPostgreSQL في قراءة المناقشة، وإرسال رسالة، وإعادة التحميل وظهورها؛ روجعت لقطة الشاشة، وظهرت تحذيرات الخطوط لأن خادم الاختبار المصغر لا يوفر إعداداتها. لا يثبت الاختبار رحلة المدرب ولا المطابقة الشكلية الكاملة أو الإنتاج.
- نجحت خمس حالات متصفح إضافية باستجابات محاكاة، تشمل الملاحظات الخاصة، وضياع استجابة الإرسال وإعادة استخدام المفتاح، وعزل الدرس عند تأخر التحميل، وحماية المسودة، ومرجع الرد إلى السؤال الصحيح.
- نجح اختبار متصفح متصل بخادم Go وPostgreSQL باستخدام حساب مدرب مُسند ومصرح له: فتح تبويب الدورة، واختيار الدرس، والرد على سؤال الطالب، ثم قراءة الرد بحساب الطالب. ونجح اختبار HTTP لعزل مدرب آخر ورفض المدرس بعد سحب نطاق المادة. عاينت لقطة المحرر؛ الاختبار يستخدم صفحة fixture للمحرر وليس لوحة المدرب كاملة.
- نجح اختبار رابط لوحة المدرب إلى إدارة الدورات الفعلية والتنبيه بأن بيانات اللوحة الأخرى تجريبية باستخدام API محاكاة، ويعرض رأس اللوحة اسم الحساب بدل اسم ثابت. لم تُستبدل بقية بيانات اللوحة التجريبية ولم تُختبر رحلة التنقل الكاملة بحساب إنتاجي.
