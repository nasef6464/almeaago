# ALMEAA Binding Rule — Strict Legacy UI Parity & Zero Redesign

## المبدأ الحاكم
المرجع البصري والوظيفي الملزم لكافة الشاشات هو:
`nasef6464/almeaacodax/main`

## المحظورات الصارمة
1. يُمنع منعاً باتاً استخدام أي مهارات أو أدوات تصميم (مثل UI UX Pro Max, Frontend Design, Impeccable, Design Taste) لتغيير الهوية أو الألوان أو الخطوط أو تخطيط الشاشات الأصلية.
2. تُستخدم أدوات ومفاهيم التصميم فقط لفحص الجودة والتجاوب (Responsiveness at 390/820/1440) وإصلاح الأخطاء دون أي انحراف عن Legacy.
3. Canvas Design مخصصة للتصميمات الإعلانية الثابتة والرسومية فقط، وليست أداة لبناء أو تعديل شاشات ولوحات ALMEAA.
4. مركز المهارات (Skills Center) جزء مستقل تماماً داخل لوحة الإدارة (`/admin-dashboard?tab=skills`) ويُمنع دمجه داخل شاشات المسارات.
